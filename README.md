# cap-fantasy-nfl-dashboard
A personal, noncomercial analytics project for managing Yahoo Fantasy Football teams.
The project aims to use the Yahoo Fantasy Sport API OAuth 2.0 authentication to retrive league settings, rosters, player statistics, standings, matchups, and waiver information.
The goal is to provide automated weekly lineup analysis, player comparisons, waiver recommendations, and trade evaluations.
This project is intended for personal use only and is currently in the planning stage.
